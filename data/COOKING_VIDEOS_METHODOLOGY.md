# Методология наполнения базы кулинарных видео

## Цель
Создать базу YouTube-видео для каждого кулинарного действия в рецептах приложения. Видео должны быть на русском и английском языках.

## Алгоритм работы

### 1. Извлечение действий из рецептов

Парсим все `steps[].instruction` из `data/offlineRecipes.ts` и преобразуем в формат:
```
"как + глагол + объект"
```

**Примеры преобразования:**
- "Разбейте яйца в миску" → "как разбить яйца"
- "Нарежьте лук кубиками" → "как нарезать лук кубиками"
- "Обжарьте курицу до золотистой корочки" → "как обжарить курицу"
- "Сформируйте котлеты мокрыми руками" → "как сформировать котлеты"

**Что НЕ включать:**
- Общие действия без контекста ("Смешайте", "Добавьте")
- Действия подачи ("Подавайте со сметаной")
- Дублирующиеся действия

### 2. Поиск видео на YouTube

Для каждого действия ищем видео:

**Русские видео:**
- Искать на `videoculinary.ru` (Бабушка Эмма) — качественные обучающие видео
- Канал "Илья Лазерсон" — профессиональные мастер-классы
- Канал "Василий Емельяненко"
- Поиск: `"[действие]" site:videoculinary.ru` или на YouTube напрямую

**Английские видео:**
- Gordon Ramsay (популярные техники)
- Joshua Weissman (современные рецепты)
- Basics with Babish
- Chinese Cooking Demystified (азиатская кухня)

### 3. Извлечение Video ID

Из URL `https://www.youtube.com/watch?v=XXXXX` берём только `XXXXX`.

Для videoculinary.ru — использовать WebFetch и искать YouTube embed в HTML.

### 4. Формат данных в cookingTechniques.ts

```typescript
{
  id: 'unique-kebab-case-id',
  name: {
    ru: 'Название на русском',
    en: 'English name'
  },
  keywords: ['ключевые', 'слова', 'из инструкций'],  // для матчинга
  video: {
    ru: {
      id: 'YouTubeVideoID',
      timestamp: 30,  // опционально, в секундах
      title: 'Название видео'
    },
    en: {
      id: 'YouTubeVideoID',
      timestamp: 15,
      title: 'Video title'
    }
  }
}
```

### 5. Матчинг с рецептами

Функция `findTechniqueForInstruction(instruction)` ищет технику по ключевым словам:
```typescript
technique.keywords.some(keyword =>
  instruction.toLowerCase().includes(keyword.toLowerCase())
)
```

## Как добавлять новые видео

1. Открыть `data/cookingTechniques.ts`
2. Найти технику по `id` или добавить новую
3. Заполнить `video.ru.id` и/или `video.en.id`
4. Добавить `timestamp` если нужно начать с определённого момента
5. Протестировать матчинг: `findTechniqueForInstruction("текст инструкции")`

## При добавлении новых рецептов

1. Проверить инструкции на наличие новых действий
2. Добавить недостающие техники в `COOKING_TECHNIQUES`
3. Найти соответствующие видео
4. Обновить этот документ если появились новые категории
