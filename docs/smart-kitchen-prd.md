**Версия:** 1.0  
**Дата:** 29 января 2026

## 🎯 Общая концепция продукта

**Умная Кухня** — комплексное мобильное AI-приложение, объединяющее:
1. Автоматическую инвентаризацию продуктов через фото и чеки
2. Подсчет калорий по фото готовой еды с контекстом
3. Генерацию рецептов из имеющихся продуктов
4. Интегрированные таймеры готовки с голосовыми подсказками
5. Контроль затрат на еду и экономию от домашней готовки
6. Заказ продуктов через интеграцию с магазинами

**Уникальное ценностное предложение:**  
Минимум кликов, максимум автоматизации — AI сам догадывается что делать, пользователь только подтверждает.

## 📱 Информационная архитектура приложения

### Главная навигация (Bottom Tab Bar)

```
┌─────────────────────────────────────────────────────────┐
│  [🏠 Главная] [🗄️ Кухня] [👨‍🍳 Готовить] [💰 Финансы] [👤 Я]  │

```

#### 1. Главная (Дневник питания)
- Лента съеденной еды с фото за сегодня
- Progress bar: калории съедено/цель
- Quick actions: "📸 Сфотографировать еду", "🍽️ Что приготовить?"

#### 2. 🗄️ Кухня (Инвентарь продуктов) — КРИТИЧНЫЙ БЛОК
**Самый важный экран приложения** — здесь происходит магия автоматизации

#### 3. 👨‍🍳 Готовить (Рецепты + Таймеры)
- "Что приготовить сейчас?" с AI-рецептами из инвентаря
- Фильтры: время, диета, сложность
- Процесс готовки с интегрированными таймерами

#### 4. 💰 Финансы (Контроль затрат на еду) — УНИКАЛЬНАЯ ФИЧА
- Визуализация трат на продукты
- Экономия от домашней готовки vs рестораны
- Аналитика: куда уходят деньги

#### 5. 👤 Я (Профиль)
- Цели, настройки, статистика
- Premium upgrade

### 1.2 Способы добавления продуктов (приоритеты по удобству)

#### Приоритет 1: 📷 Фото холодильника/шкафов (ГЛАВНЫЙ СПОСОБ)

**Сценарий использования:**
1. Пользователь открывает холодильник
2. Делает 1 фото всего содержимого
3. AI распознает ВСЕ видимые продукты за 5-10 секунд
4. Показывает результат с overlay на фото
5. Пользователь свайпает каждый продукт для коррекции количества

**Gesture-based коррекция (КРИТИЧНО ДЛЯ МИНИМУМА КЛИКОВ):**

```
Свайп вправо на продукте → "Больше" → quantity × 1.5
Свайп влево на продукте → "Меньше" → quantity × 0.7
Свайп вниз на продукте → "Закончилось" → удалить из инвентаря
Тап на продукте → модальное окно детальной коррекции
```

#### Приоритет 2: 📄 Сканирование чеков (АВТОМАТИЗАЦИЯ ПОСЛЕ ПОКУПОК)

**Сценарий использования:**
1. Пользователь купил продукты → получил чек
2. Делает фото чека или сканирует QR-код чека (ФНС API)
3. AI извлекает все купленные товары

### 2.2 Экономические расчеты в рецептах (УНИКАЛЬНАЯ ФИЧА)

#### Расчет себестоимости блюда:

Система рассчитывает пропорциональную стоимость каждого ингредиента:
- Если продукт из инвентаря → берём его реальную цену
- Если продукта нет → средняя рыночная цена

#### Оценка ресторанной цены:

База данных типичных ресторанных цен с корректировками:
- +20% если премиум ингредиенты (авокадо, лосось)
- +30% если сложное блюдо
- -15% если простое (яичница, каша)

### 2.3 Генерация AI-изображений блюд (Premium фича)

**ГЕНИАЛЬНАЯ ОПТИМИЗАЦИЯ: Переиспользование изображений**

#### Стратегия #1: Perceptual Hashing для дедупликации

```javascript
// Когда генерируем изображение:
// 1. Создаём semantic fingerprint рецепта
// 2. Ищем похожие рецепты с уже сгенерированными фото
// 3. Если similarity > 85% → переиспользуем фото
// 4. Если не нашли → генерируем новое

// Экономия: 80% запросов используют кэш
// Без кэша: 5000 × $0.04 = $200
// С кэшем: 1000 × $0.04 = $40
// ЭКОНОМИЯ: $160 (80%)!
```

#### Стратегия #2: Ingredient-based Image Caching

```javascript
// База: sorted ingredient combo → CDN URL
const cache = {
  "chicken+rice+carrot+onion": "https://cdn.app.com/ai/abc123.jpg",
  "eggs+tomato+cheese": "https://cdn.app.com/ai/def456.jpg"
}

// Проверяем кэш перед генерацией
// Cache hit rate: 80%+ → огромная экономия
```

#### Стратегия #3: Progressive Generation

Не генерируем изображения сразу для всех рецептов:
- В списке рецептов → placeholder или stock фото
- В детальном просмотре → генерируем on-demand (Premium)
- При готовке → обязательно показываем

## 🎨 UX PRINCIPLES

### 1. Минимум кликов = максимум автоматизации

**Правило:** Если AI может догадаться - не спрашивай пользователя

### 2. Gesture-first интерфейс

- Swipe right = увеличить/больше/да
- Swipe left = уменьшить/меньше/нет
- Swipe down = удалить/закончилось
- Long press = детальная информация
- Tap = быстрое действие

### 3. Контекстные подсказки

Показывать действия в нужный момент:
- Готовишь → "Использовали молоко?"
- Продукт портится → push с рецептом
- Вечер → "Что приготовить на ужин?"

### 4. Визуализация > Текст

Показывать фото холодильника с overlay вместо текстовых списков

### 5. Геймификация экономии

- Показывай экономию, не только траты
- Badges за ачивки
- Progress bars
- Сравнения (дома vs ресторан)
