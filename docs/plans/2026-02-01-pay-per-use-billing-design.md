# Pay-Per-Use Billing System Design

**Дата:** 2026-02-01
**Статус:** Approved

## Обзор

Переход с подписочной модели на pay-as-you-go оплату за AI-токены. Приложение бесплатное, юзер платит только за использование AI-функций.

## Бизнес-модель

### Ценообразование

| Действие | Себестоимость | Цена юзеру | Наценка |
|----------|---------------|------------|---------|
| Скан еды | ~$0.025 | $0.04-0.05 | 60-100% |
| Скан чека | ~$0.03 | $0.05-0.06 | 67-100% |
| Скан холодильника | ~$0.03 | $0.05-0.06 | 67-100% |
| AI рецепты | ~$0.003 | $0.005-0.01 | 67-233% |

### Пакеты пополнения

| Пакет | Цена | Скидка | Примерно хватит на |
|-------|------|--------|-------------------|
| Starter | $5 | — | ~100 сканов |
| Popular | $10 | 10% | ~220 сканов |
| Power User | $25 | 20% | ~600 сканов |
| Custom | от $1 | — | — |

### Отображение

- Показываем только **доллары** (не токены) — скрываем наценку
- В UI: `💰 $7.42 [+ Пополнить]`

## User Flow

### Trial Period (3 дня)

```
День 1: Установка → безлимитный доступ (анонимно)
        Показываем "виртуальные расходы"

День 2: Продолжаем использовать
        Hint: "Войди через Google чтобы сохранить прогресс"

День 3: Warning: "Последний день trial!"
        Показываем итог: "Было бы потрачено $X.XX"

День 4: Trial закончился
        Бонус $0.50 на счёт
        Блок до пополнения после исчерпания бонуса
```

### Аккаунт

- **Анонимно до оплаты** — device_id для trial
- **Google Sign-In при пополнении** — миграция данных на user_id
- Один клик авторизация когда юзер уже мотивирован

### Баланс и лимиты

```
Баланс > $0.50  →  Всё работает
Баланс < $0.50  →  Warning "Баланс заканчивается"
Баланс = $0     →  Кредит доверия до -$0.50
Баланс < -$0.50 →  Жёсткий блок
```

## Структура БД

```sql
-- Баланс юзера
CREATE TABLE user_balance (
  id SERIAL PRIMARY KEY,
  user_id VARCHAR(255) UNIQUE NOT NULL,  -- Google ID или device_id
  balance_cents INTEGER DEFAULT 0,        -- в центах для точности
  trial_ends_at TIMESTAMP,                -- когда заканчивается trial
  trial_usage_cents INTEGER DEFAULT 0,    -- виртуальные расходы за trial
  created_at TIMESTAMP DEFAULT NOW(),
  updated_at TIMESTAMP DEFAULT NOW()
);

-- История транзакций
CREATE TABLE transactions (
  id SERIAL PRIMARY KEY,
  user_id VARCHAR(255) NOT NULL,
  type VARCHAR(50) NOT NULL,              -- 'topup' | 'usage' | 'trial_bonus' | 'trial_virtual'
  amount_cents INTEGER NOT NULL,          -- + пополнение, - списание
  description TEXT,                       -- "Скан еды", "PayPal $10"
  paypal_order_id VARCHAR(255),           -- для пополнений
  created_at TIMESTAMP DEFAULT NOW()
);

-- Детальный usage для статистики
CREATE TABLE usage_log (
  id SERIAL PRIMARY KEY,
  user_id VARCHAR(255) NOT NULL,
  action_type VARCHAR(50) NOT NULL,       -- 'food_scan' | 'receipt_scan' | 'recipe_ai' | ...
  cost_cents INTEGER NOT NULL,
  metadata JSONB,                         -- доп. данные (модель, токены и т.д.)
  created_at TIMESTAMP DEFAULT NOW()
);

-- Индексы
CREATE INDEX idx_user_balance_user_id ON user_balance(user_id);
CREATE INDEX idx_transactions_user_id ON transactions(user_id);
CREATE INDEX idx_transactions_created_at ON transactions(created_at);
CREATE INDEX idx_usage_log_user_id_created ON usage_log(user_id, created_at);
```

## Бесплатные функции (из БД)

Не тратят баланс юзера:

- **850+ офлайн рецептов** — уже есть в `offlineRecipes.ts`
- **Nutrition данные** — популярные продукты из локальной БД
- **Мотивационные фразы** — 100+ захардкоженных фраз
- **Базовые расчёты** — TDEE, BMR, нормы воды

## Техническая реализация

### PayPal Integration

1. **PayPal Checkout** (простой вариант для начала)
2. Кнопка → PayPal popup → оплата → webhook → начисление
3. Поддержка карт без аккаунта PayPal

### API Endpoints

```
POST /api/billing/create-order     — создать PayPal order
POST /api/billing/capture-order    — подтвердить оплату (webhook)
GET  /api/billing/balance          — получить баланс
GET  /api/billing/usage            — статистика использования
POST /api/billing/charge           — списать за действие (internal)
```

### Фронтенд изменения

1. **BillingContext** — глобальный стейт баланса
2. **BalanceIndicator** — компонент в шапке
3. **TopUpModal** — модал пополнения
4. **UsageStats** — статистика в настройках
5. **EconomySettings** — настройки экономии
6. **TrialBanner** — баннер во время trial

### Middleware для списания

```typescript
// Перед каждым AI-вызовом
const chargeForAI = async (userId: string, action: string, cost: number) => {
  const balance = await getBalance(userId);

  if (balance.isTrialActive) {
    // Trial — считаем виртуально
    await logTrialUsage(userId, action, cost);
    return { allowed: true };
  }

  if (balance.cents < -50) {
    // Превышен кредит
    return { allowed: false, reason: 'insufficient_balance' };
  }

  // Списываем
  await deductBalance(userId, cost);
  await logUsage(userId, action, cost);
  return { allowed: true };
};
```

## Миграция существующих юзеров

1. **Pro юзеры** — конвертируем оставшийся срок в баланс ($10/месяц)
2. **Trial юзеры** — продолжают trial, потом новая модель
3. **Остальные** — начинают с новой модели

## Метрики успеха

- **Conversion rate** trial → paid: цель >5%
- **ARPU** (Average Revenue Per User): цель $3-5/месяц
- **Churn** после первого пополнения: цель <30%

## Риски

1. **Юзеры не пополняют** — митигация: бонус $0.50, низкий порог входа
2. **Абьюз trial** — митигация: device fingerprinting, лимит на IP
3. **PayPal комиссии** — ~3.5%, заложено в наценку
